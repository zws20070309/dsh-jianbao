# 简报版式规范（实测自参考 PDF）

唯一权威样本：`远端仓库参考内容/简报/2026下/…〔2026〕74号….pdf`（Word for Microsoft 365 导出）。
所有数字都是从这个 PDF 的 span 级 origin（基线）反推的，单位 **bp**（1bp = 1/72in = PDF 用户单位）。

| 项 | 值 |
|---|---|
| 纸张 | 595.32 × 841.92 bp（A4） |
| 页边距 | 上 104.90 / 下 99.25 / 左 79.40 / 右 73.70 |
| 版心 | 442.22 bp 宽 |
| 固定行距 | 28.80 bp（全文，含标题） |

## 验收

写完必须跑几何对比，容差 0.5bp：

    node dsh-jianbao/tools/geometry-diff.mjs 产出.pdf 参考.pdf --tol 0.5

退出码 0 = 全在容差内。PDF 里图的位置绕排会让块顺序变化，工具按「去空白文本」对齐，不受顺序影响。
